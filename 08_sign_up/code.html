To protect user credentials, SmartAssist AI never saves passwords to localStorage or mock memory. Real account creation requires an official authentication provider like Supabase Auth.

Quick Setup Steps:
  1. Create a free project at supabase.com
  2. In Supabase Dashboard, go to Project Settings → API
  3. Add your credentials to the project root .env:
SUPABASE_URL=https://your-project-id.supabase.co SUPABASE_ANON_KEY=eyJhbGciOi...

Once saved in .env, registration immediately activates user creation, password hashing (bcrypt), and email confirmation.
