Process vs Thread

A process is a program in execution with its own memory space and system resources. A thread is a smaller unit of execution within a process.

layers
Process Scope
Heavy isolation: Owns PCB, registers, stack, heap, and file descriptors.

Thread Scope
Light execution: Shares text, data, and OS handles, maintaining private stacks.

Multiple threads:

Multiple threads within a process can handle tasks such as processing input or performing background work (e.g., rendering pixels while asynchronously downloading video data).

python threading_example.py 
import threading
import time

def background_task(task_name):
    print(f"Thread {task_name}: running concurrently")
    time.sleep(1)
    print(f"Thread {task_name}: finished")

# Spawn two lightweight threads inside the current process
t1 = threading.Thread(target=background_task, args=("Alpha",))
t2 = threading.Thread(target=background_task, args=("Beta",))

t1.start()
t2.start()

t1.join()
t2.join()
print("Main process execution resumed")
key
Key Takeaway

Processes provide stronger isolation, while threads enable concurrent work within the same process.
