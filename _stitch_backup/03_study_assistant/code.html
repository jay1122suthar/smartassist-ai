Topic: CPU Scheduling

lightbulb Core Definition

CPU scheduling is the fundamental operating system mechanism that selects which ready process should execute next from the ready queue, maximizing CPU utilization and multi-programming throughput.

schema Prominent Scheduling Algorithms 4 Key Variants
FCFS Non-preemptive
First Come, First Served

Executes in queue arrival order. Simple to implement via FIFO queue, but prone to high turnaround times via the convoy effect.

SJF Optimal
Shortest Job First

Dispatches processes with minimal burst times first. Provides optimal average waiting time, though exact next-burst lengths require heuristics.

Round Robin Preemptive
Time-Slice Partitioning

Each process receives a cyclic, fixed time quantum (q). Context shifts occur systematically upon quantum expiry.

Priority Preemptive/Non
Rank-Ordered Allocation

Processes execute according to priority integers. Starvation is actively mitigated through progressive aging techniques.

tips_and_updates
Exam Revision Tip

Round Robin is especially useful in modern time-sharing and interactive architectures because it gives processes repeated, deterministic opportunities to execute without starvation.

Which CPU scheduling algorithm uses a fixed time quantum?
